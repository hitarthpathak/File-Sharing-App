# File-Sharing-App

A Full-Stack File Sharing Web Application.

### Front-End : React JS, Tailwind CSS, React Bootstrap
### Back-End : Firebase (Firebase Emulator) + Node JS SMTP Server

## How To Use

### Terminal Commands :-
### Front-End (React JS) :
```
npm run dev
```
### Back-End (Firebase Emulator) :
```
npx firebase emulators:start --project demo-file-sharing-app
```
### Back-End (Node JS SMTP Server) :
```
node server.js
```

### Ports :-
### Front-End (React JS) :
```
http://localhost:5173/
```
### Back-End (Firebase Emulator) :
```
http://127.0.0.1:4000/
```
### Back-End (Node JS SMTP Server) :
```
http://localhost:3001/
```
